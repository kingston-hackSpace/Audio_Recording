### WIRING

| Mic pin        | Meaning     | Teensy 4.1         |
| -------------- | ----------- | ------------------ |
| **3V**         | Power       | 3.3V               |
| **GND**        | Ground      | GND                |
| **BCLK**       | Bit clock   | Pin 21             |
| **LRCLK / WS** | Word select | Pin 20             |
| **DOUT**       | Audio data  | Pin 8              |
| **SEL**        | L/R select  | GND (left channel) |
